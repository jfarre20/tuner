TUNER

Welcome

This turns a folder of video files into a cable box: always-on channels you flip through, snow in between, a Prevue-style guide. Nothing is uploaded or rearranged; it only reads your files.

The next screens ask for your video folder (required) and a few optional extras: network logos, station idents, hold music, a WeatherStar channel, and how the picture should look. Everything can be changed later in this tool, or in the tuner with the S key.

Folders

Only the content library is required. Point it at a folder of mp4 / mkv / mov / webm / avi files; every file becomes part of a channel's loop. "Channels" is how many channels the folder is dealt across (fewer channels = longer loops).
Lineup channels below add to this if numbered higher.
Logo PNG file names become network names (MTV (US).png → MTV). Idents: one subfolder per network, matched by name.

WeatherStar

Optional. A Weather Channel "local forecast" channel, served by a local copy of ws3kp (git clone https://github.com/netbymatt/ws3kp, then npm install in it; needs Node.js). Pick that folder and enter your ZIP. Leave the folder empty to skip.

Picture

The CRT tube adds scanlines, curvature and noise (C toggles it in the tuner). FIT keeps each file's shape; STRETCH fills the window. All of this is also in the tuner's S menu.

Features

Logo bugs, corner clocks and news crawls need the logo folder; idents need the idents folder; hold music needs the music folder. They quietly do nothing otherwise.
